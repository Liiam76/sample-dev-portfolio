# content/ : the words on the site

Every section has one file here. All five design variants read these same files.
Edit a file, and every variant changes. There is no second copy anywhere.

| File | Section |
|---|---|
| 01-hero.md | Name, role, headline |
| 02-about.md | About |
| 03-experience.md | Work history |
| 04-projects.md | Selected projects |
| 05-skills.md | Tools |
| 06-contact.md | Contact and footer |

The block between the two `---` lines is frontmatter: structured facts such as each job's
company and dates. Keep the field names on the left the same. Edit the words on the right.
